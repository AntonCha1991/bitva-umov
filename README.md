# 🧠 Битва умов

Интерактивная викторина для компании друзей.

## Как устроена игра
- 10 раундов и четыре варианта ответа на каждый вопрос.
- Участники по очереди отвечают на вопросы.
- На ответ даётся 30 секунд.
- В обычных раундах правильный ответ приносит 10 очков.
- В раундах «РИСК» игрок может рискнуть накопленными очками.
- После раунда показываются правильный ответ, объяснение и счёт.

## Запуск
После добавления файла `index.html` и включения GitHub Pages игру можно будет открыть в браузере по публичной ссылке.
